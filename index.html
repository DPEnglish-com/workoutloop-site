日历会把一次缺席，
变成一笔账。

大多数健身应用把训练钉在星期几。周二没练，那天就永久留空，进度条退回去，你只好补课。补到第三次，就不太想打开了。

WorkoutLoop 把计划排成一个环：练完当前这一项，环才往前一格。隔三天还是三周，回来时它还在原地等你。

没有连胜，没有断签提醒，没有积分。

一次训练里会发生什么

  1. 开始

    首页只回答一个问题：现在该练什么。按下开始就进入。

  2. 跟着环走

    计时动作走环形倒计时，数字等宽，跳动时不左右晃。

  3. 不用看屏幕

    中文人声播报，音量上完成本组，音量下暂停。屏幕可以一直锁着。

  4. 练完自动往下走

    最后一个动作结束就结算，队列推进到下一项，中途打断也能续上。

功能

编排

两种动作顺序
分组做完一个动作的全部组数再换，或按列表逐组轮换。
左右侧独立
单侧动作分开添加，各自记组数，不必心里数到哪边。

使用

音量键控制
音量上完成本组或跳过休息，音量下暂停。手上有汗也不用点屏幕。
人声播报
动作开始、最后十秒逐秒倒数、休息结束，都有中文播报。

数据

本地导出
全部训练数据导出成 JSON，换设备或重装时导入恢复。
没有网络代码
不申请网络权限，因此物理上无法上传你的数据。

另有深色模式、横竖屏自适应、训练中改目标、整套复制。

你的训练记录，
不必经过任何人的服务器。

这不是隐私政策里的承诺，而是权限清单上可以核对的事实。

没有注册，没有账号，没有云端同步。数据存在手机本地的数据库里，卸载就等于彻底删除。

  • 网络权限 未申请

    权限清单里没有 INTERNET，系统层面无法发起网络请求。

  • 崩溃上报 无

    不集成任何分析或崩溃采集 SDK。

  • 体重字段 加密存储

    以 AES-256-GCM 加密后落盘，每次写入使用随机 IV。

  • 备份文件 不含体重

    导出的 JSON 刻意排除体重表，密文换台设备也解不开。
