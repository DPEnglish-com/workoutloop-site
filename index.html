大多数健身应用把训练钉在星期几。周二没练，周二就永久留空，进度条退回去，然后你开始补课。补课很累，累到第三次就不想打开了。

WorkoutLoop 换了个做法：训练计划排成一个环，你练完当前这一项，环才往前走一格。中间隔了三天还是三周，回来时它还在原地等你。

没有连胜纪录，没有断签提醒，没有积分。这些机制擅长让你为数据焦虑，而不是让你练得更好。

一次训练里会发生什么

  1. 开始

    首页只回答一个问题：现在该练什么。一张卡片给出计划名、动作数量和预估时长，按下开始即进入。

  2. 跟着环走

    计时动作走环形倒计时，数字用等宽字体，跳动时不左右晃。次数动作的环表示本动作的组数进度。屏幕离你两米也读得清。

  3. 不用看屏幕

    中文人声播报动作开始、最后十秒倒计时、休息结束。手上有汗或戴着手套时，按音量上完成本组，音量下暂停。屏幕可以一直锁着。

  4. 练完自动往下走

    最后一个动作结束就结算，训练队列自动推进到下一项。中途被打断也没关系，快照会存住当时的阶段，回来接着倒数。

功能

编排

两种动作顺序
分组模式做完一个动作的全部组数再换下一个；轮换模式按列表逐组穿插，适合平板支撑、臀桥这类交替训练。
左右侧独立
单侧动作可以分别添加，各自记录组数，不必在心里数到哪一边了。
训练中改目标
今天状态好多做两组，只是这一次的事，不会改掉计划模板。
整套复制
训练包和单个计划都能复制成副本，改一份不影响另一份。

使用

音量键控制
音量上完成本组或跳过休息，音量下暂停与继续。训练时不必摘手套去点屏幕。
人声播报
动作开始、最后十秒的逐秒倒数、休息结束与训练完成都有中文播报。
深色模式
默认跟随系统，也可手动指定。夜间或昏暗房间里不刺眼。
横竖屏都适配
横屏时训练页左右分栏，适合把平板架在支架上远远地看。

数据

本地导出
全部训练数据可导出成一个 JSON 文件，换设备或重装时导入恢复。
体重加密
体重与备注用 Android Keystore 的 AES-256-GCM 加密后才落盘，明文不经过数据库。
应用锁
可选开启，用指纹或设备密码拦在界面之前。设备没有可用凭据时会自动关闭，不会把你锁在门外。
没有网络代码
应用不申请网络权限，因此它在物理上无法上传你的任何数据。

你的训练记录，
不必经过任何人的服务器。

没有注册，没有账号，没有云端同步。训练数据存在手机本地的 SQLite 数据库里，卸载应用就等于彻底删除。

这不是隐私政策里的承诺，而是权限清单上可以核对的事实。

  • 网络权限 未申请

    APK 的权限清单里没有 INTERNET，应用在系统层面无法发起网络请求。

  • 崩溃上报 无

    不集成任何分析或崩溃采集 SDK。

  • 体重字段 加密存储

    数据库中为密文，格式为 base64(iv):base64(密文)，每次写入使用随机 IV。

  • 备份文件 不含体重

    导出的 JSON 刻意排除体重表。密文依赖本机密钥，带到别的设备也解不开。
